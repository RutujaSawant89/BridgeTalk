# 🌐 BridgeTalk Translator App

BridgeTalk is a React Native-based language translation app that helps users break language barriers and communicate effortlessly. Built with a clean UI, it supports multiple languages and integrates with an AI translation API to provide real-time translations.

## 🚀 Features

- 🌍 Translate between 20+ global and regional languages
- 🎨 Sleek modern UI with animated welcome screen (Lottie)
- 🔄 Language dropdowns using `react-native-dropdown-picker`
- 📤 API integration using Groq AI (LLaMA model)
- 🔐 Built with Expo and supports Android

## 📱 Screens

- **Landing Screen**: Welcome animation with a "Get Started" button
- **Translator Screen**: Dropdowns for selecting languages, input box, translation result display

## 📦 Tech Stack

- React Native + Expo
- Lottie for animations
- Axios for API requests
- Groq API with LLaMA-3 model
- react-native-dropdown-picker
- expo-linear-gradient
